# AI-Based Bulk Fruit Detection

Mini Project (23VAIS09) by Shaganaa S (24UVA050).

Upload a bulk-fruit image. A Roboflow Workflow (YOLO-based detection) detects the fruits, draws bounding boxes, and shows the fruit type and total count.

Tech: Python, Flask, Roboflow Workflows, YOLO/CNN, HTML/CSS/JS.

Deploy: Build command "pip install -r requirements.txt", start command "gunicorn app:app", and set the environment variable ROBOFLOW_API_KEY.
